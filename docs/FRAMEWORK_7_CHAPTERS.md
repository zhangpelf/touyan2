# 7 维全景评估框架深度指南 (FRAMEWORK_7_CHAPTERS)

> 本文档系统阐述 `touyan2` 产线落地投研分析引擎的核心评估方法论。针对地方政府招商引资局、高新区管委会、国资产业引导基金的投前研判场景，提供标准化的研判准则与量化指标。

---

## 核心定位：财务 VC 投资 vs. 国资招商落地的本质差异

在传统的风险投资（VC/PE）中，分析核心通常是**未来估值翻倍倍数、IRR 与上市/并购退出通道**；但在地方政府与国资平台视角下，产线落地项目的核心诉求是**“要素置换价值”与“风险托底保障”**：

| 评估维度 | 财务 VC / 私募基金 | 地方政府 / 国资产业引导基金 |
| :--- | :--- | :--- |
| **首要目标** | 财务回报率（IRR、MOIC）、IPO/并购退出 | 固投落地、产值税收、链主带动、本地就业 |
| **资金性质** | 市场化有限合伙资金，容忍高失败率 | 财政配套/国资资金，严格防范国有资产流失 |
| **关注核心** | 商业模式爆发力、团队股权激励、高毛利 | 真实生产能力、设备与厂房投入真实性、环保合规 |
| **退出约束** | 回购条款、优先清算权 | 亩均税收对赌、产线未达标违约追偿、厂房回购 |
| **风险容忍** | 允许高技术风险，博取非对称收益 | 零容忍“套取政策补贴”、“空壳圈地”、“一女多嫁” |

## 第一章 项目概览：厘清“谁在投资、投向何处”

### 1.1 研判核心
本章是整个投研报告的基石，主要剥离企业商业计划书中的宣传话术，将其锚定为不可篡改的硬性数据。重点回答：**谁是主投资方？总投资中真金白银是多少？杠杆率多高？**

### 1.2 必备评估模块与表格
- **核心投资亮点摘要（前置 4-6 条）**：每条包含“加粗核心数据锚点 + 一句话事实支撑”，拒绝泛泛而谈的形容词。
- **基本信息表**：公司全称、实际控制人、成立年份、实缴资本、产线选址诉求、总投资额。
- **投资节奏与分期规划表**：一期/二期/三期的时间节点、阶段固投、铺底流动资金。
- **资金用途拆解表**：设备购置、土建装修、研发支出、流动资金占比。

### 1.3 核心风控红旗（Red Flags）
- ⚠️ **总投水分过大**：企业将未来 5 年乃至 10 年的不可控远期规划全部计入“总投资”，实际首期出资不足 10%。
- ⚠️ **重度依赖政府垫资**：企业自有出资比例低于 30%，要求政府产业基金或国资平台兜底 70% 以上资金。

## 第二章 行业与市场分析：检验赛道天花板与真实需求

### 1.1 研判核心
验证项目所处行业是否符合国家产业战略导向（如高端装备、新材料、集成电路、生物医药、绿色低碳），并检验项目方引用的市场规模数据是否存在虚假繁荣。

### 1.2 关键指标与分析模型
- **市场规模与复合增速 (CAGR)**：采用至少两个独立第三方权威机构研报（券商研报、IDC、弗若斯特沙利文等）进行交叉比对。
- **供需平衡与替代逻辑**：当前国内有效产能、进口依存度、国产替代渗透率曲线。
- **竞争格局与集中度 (CR5 / HHI 指数)**：绘制竞争格局矩阵，明确头部大厂的市场份额及本项目的生存空间。

### 1.3 核心风控红旗
- ⚠️ **赛道伪需求/产能过剩**：处于行业产能出清周期（如低端光伏、部分电池材料等），新扩产线存在投产即停产风险。
- ⚠️ **夸大市场占有率**：在极窄的自定义细分词条中自称“全国第一”，实际可触达市场规模不足数亿元。

## 第三章 项目竞争力评估：深挖技术护城河与供应链壁垒

### 1.1 研判核心
考察技术真实来源（自研、高校转化、代工改标）、研发团队连续性，以及是否有标杆客户真实买单。

### 1.2 评估矩阵
- **SWOT 优劣势矩阵**：系统梳理团队、技术、产品、在手客户 4 个维度的壁垒。
- **核心产品关键参数对标表**：将项目方产品的加工精度、良品率、单位耗能、故障间隔时间（MTBF）等核心参数与国际/国内标杆同行横向逐项拉齐。
- **客户与在手订单验证**：区分“框架合作意向书（LOI）”与“排他性采购合同 / 银行打款订单”。

### 1.3 核心风控红旗
- ⚠️ **核心技术存在职务发明争议**：技术带头人系从科研院所或头部竞品离职，未彻底脱密，存在知识产权侵权诉讼隐患。
- ⚠️ **缺乏真实自研能力**：采购进口关键元器件进行组装改标，核心控制器或算法受制于人。

## 第四章 财务效益分析：审慎测算投资回收期与抗风险韧性

### 1.1 研判核心
地方国资投研不同于企业自吹自擂的财务模型。分析师必须主动剔除过于乐观的毛利率预期，引入**压力测试（Stress Testing）**与**敏感性分析**。

### 1.2 必备测算维度
- **单期产值与净利润预测**：爬坡期产值、达产期产值、净利率估算。
- **静态与动态投资回收期**：考虑折现率（通常按地方国资资金成本 6%~8% 计）下的资金回正周期。
- **盈亏平衡点 (BEP) 测算**：产能利用率达到多少时项目可实现现金流平衡。
- **敏感性测算表**：模拟原材料涨价 10%、产品售价下调 10%、产能爬坡延期 6 个月等极限情境下对净利润的影响。

## 第五章 地方落地价值评估：锚定“税收、就业与强链补链”

### 1.1 研判核心
本章是**招商部门汇报地方领导班子会、产投评审会的关键依据**。回答“这个项目引进来，给地方带来什么实惠？”

### 1.2 量化考核指标
- **亩均产值与亩均税收**：产线达产后每亩工业用地的产值（如不低于 800 万元/亩）与年纳税额（如不低于 50 万元/亩）。
- **就业带动与人才结构**：吸纳产业技术工人、高学历研发人员的就业人数。
- **产业链配套带动**：能否带动本地上下游供应链零部件采购、能否填补本地园区特色产业图谱的空白点。
- **要素诉求评估**：项目方索要的厂房代建面积、免租期、能耗指标（标煤/千瓦时）、污水排放量是否在地方承载力范围内。

## 第六章 风险分析与缓释：建立立体风控防火墙

### 1.1 研判核心
显式化列出项目落地全周期的潜在暴雷点，并逐条配齐可执行、可追溯的缓释抓手。

### 1.2 四大关键风险维度
1. **技术迭代与良率风险**：产线量产良品率不及预期，导致报废成本攀升。
2. **市场竞争与价格战风险**：行业巨头降价挤压，客户转单。
3. **工程建设与周期风险**：厂房改建延误、重型设备进口清关延迟。
4. **地方履约与对赌风险**：企业达到免税或拿完补贴后“异地迁址”或“空壳化”。

---

## 第七章 综合评估与建议：明确决策结论与尽调抓手

### 1.1 研判核心
给出毫无模棱两可的最终决策态度：**【建议引进落地 / 审慎附条件推进 / 暂缓或不推荐】**。

### 1.2 决策工具
- **招商落地综合评分卡**：团队背景（20%）、技术产品力（25%）、市场前景（20%）、落地效益（20%）、风控合规（15%）。
- **分期投资与里程碑绑定方案**：将国资基金出资、厂房免租补贴分阶段与“设备到厂安装调试完成”、“首批客户验收报告签署”、“第一年度纳税额达标”等客观证据硬性挂钩。
- **投前尽调排雷重点（Red Flag List）**：为后续实地走访、律师事务所、会计师事务所尽调出具核心清单。
