# 投前尽职调查全量排雷清单 (DUE_DILIGENCE_CHECKLIST)

> 本清单专为地方政府招商引资处室、国资平台投资部及产业母基金设计。
> 在根据 `touyan2` 框架形成初步初审投研报告后，在正式上会出资前，必须对照本清单逐项完成实地尽调核验与证据归档。

---

## 模块一：主体资格与股权合规（5 项排查）

| 序号 | 排查重点 | 风险警示 (Red Flag) | 验证方式与核心证据底稿 |
| :--- | :--- | :--- | :--- |
| 1.1 | **实收资本真实性** | 注册资本数亿元但实缴为零，主要出资人通过短期过桥资金抽逃出资 | 查验银行打款凭证、验资报告及会计账簿银行流水 |
| 1.2 | **股权代持与实际控制人** | 显名股东系挂名代理人，背后存在失信被执行人或公职人员代持 | 调取工商内档、穿透穿刺穿透核查实控人个人征信报告 |
| 1.3 | **历史融资对赌协议** | 早期投资机构持有强行回购、清算优先权，且到期回购压力巨大 | 调阅历史各轮《增资协议》《股东协议》原件及补充协议 |
| 1.4 | **重大涉诉与仲裁风险** | 主体或核心高管卷入借贷纠纷、劳务纠纷或涉诉财产保全保全 | 中国裁判文书网、执行信息公开网、企查查司法案件穿透 |
| 1.5 | **“一女多嫁”多地套补风险** | 项目方在多个城市同时注册实体，用同一套技术方案重复申报落地补贴 | 检索全国各地政企合作签约新闻、异地分子公司开立记录 |

## 模块二：知识产权与技术自研深度（6 项排查）

| 序号 | 排查重点 | 风险警示 (Red Flag) | 验证方式与核心证据底稿 |
| :--- | :--- | :--- | :--- |
| 2.1 | **专利权属与职务发明** | 核心发明人曾任职科研院所或头部外企，专利权存在归属争议或潜在诉讼 | 离职协议、竞业限制协议、原单位知识产权豁免证明 |
| 2.2 | **核心软件著作权与源码** | 所谓自主可控算法实际基于开源框架简单套壳，不具备底层修改能力 | 现场代码审查（Code Review）、关键算子底层架构说明书 |
| 2.3 | **专利有效性与质押状态** | 核心专利已过保护期、因欠缴年费终止，或已被大额质押给第三方机构 | 国家知识产权局专利登记簿副本、专利缴费凭据 |
| 2.4 | **关键元器件供应链断供** | 核心激光器、控制芯片或高精减速机依赖进口单一渠道，面临断供风险 | 原材料采购明细账、供应商合同、关键零部件安全库存量 |
| 2.5 | **自研产线 vs 贴牌外协** | 号称自建产线，实为向第三方代工厂贴牌代工（OEM/ODM）赚取差价 | 实地考察生产基地、固定资产设备台账、车间工人考勤表 |
| 2.6 | **关键技术认证与资质门槛** | 缺乏特定行业准入门槛（如医疗器械注册证、武器装备科研生产许可） | 国家主管部门颁发的许可证件原件核对、抽查批号真实性 |

## 模块三：财务真实性与资金穿透（7 项排查）

| 序号 | 排查重点 | 风险警示 (Red Flag) | 验证方式与核心证据底稿 |
| :--- | :--- | :--- | :--- |
| 3.1 | **关联交易“左手倒右手”** | 营收大额来自实际控制人控制的其他关联公司，人为虚增业绩与产值 | 穿透前五大客户与供应商股权关联；剔除关联交易重测营收 |
| 3.2 | **研发费用资本化调节** | 将大额日常行政费用、生产耗材计入研发费用以获取高新认证或补贴 | 抽查研发工时记录表、研发立项报告、会计师专项审计报告 |
| 3.3 | **应收账款账龄与坏账风险** | 账面营收高企但现金流枯竭，大额应收账款账龄超 1 年且未计提坏账 | 银行对账单、重要客户走访与外部询证函回函 |
| 3.4 | **存货跌价与呆滞库存** | 仓库堆积大量淘汰型号半成品，虚增账面存货资产抵消亏损 | 现场盘点存货仓库、核查库龄分析表与呆滞料报废处理记录 |
| 3.5 | **固定资产设备真实估值** | 项目方将翻新旧设备虚标为全新进口设备，虚构固定资产投资额 | 设备采购原始发票、海关报关单据、第三方资产评估报告 |
| 3.6 | **银行负债与民间借贷** | 账外存在隐性民间借贷或高息小贷借款，企业面临资金链断裂 | 调取中国人民银行企业信用报告、实控人征信及法务问询 |
| 3.7 | **纳税合规与历史欠税** | 存在买卖增值税专用发票、偷漏税或违规享受税收减免历史 | 税务局纳税证明、完税凭证原件及近三年税务纳税申报表 |

## 模块四：客户基础与真实订单（4 项排查）

| 序号 | 排查重点 | 风险警示 (Red Flag) | 验证方式与核心证据底稿 |
| :--- | :--- | :--- | :--- |
| 4.1 | **意向性框架 vs 锁量锁价** | 将“战略合作备忘录（MOU）”宣称为“在手锁定订单”以夸大销售 | 逐一调阅正规有法律效力的供货合同、PO 单（采购订单） |
| 4.2 | **客户集中度过高风险** | 前两大客户贡献超过 80% 的营收，且客户自身经营出现重大波动 | 统计前十大客户营收占比；评估核心客户替换代价 |
| 4.3 | **退货率与售后索赔** | 产品在客户端故障频发、验收困难，存在重大退货或违约索赔隐患 | 客户验收报告、质保期售后维修记录、退换货台账 |
| 4.4 | **标杆客户独立走访** | 伪造大客户采购背书，实际并未通过下游主机厂的供应商入围验厂 | 尽调小组实地走访下游采购总监或技术负责人进行封闭访谈 |

## 模块五：地方落地与对赌履约能力（8 项排查）

| 序号 | 排查重点 | 风险警示 (Red Flag) | 验证方式与核心证据底稿 |
| :--- | :--- | :--- | :--- |
| 5.1 | **落地主体设立与注册地** | 企业承诺产线落地，但实际以分公司形式运营，税收关系仍留在母地 | 必须设立独立法人主体，且约定注册地、纳税地、统计关系三统一 |
| 5.2 | **分期固投兑现保障** | 企业在首期拿完政府补贴后无力推进二期，产线处于半停工状态 | 设立监管账户，约定政府基金出资以企业自筹资金同比例到位为前提 |
| 5.3 | **亩均税收对赌可行性** | 承诺过高的亩均税收，但在当前毛利模型下根本不可能完成 | 对照同类型园区标杆企业亩均产出数据测算实际达标可能性 |
| 5.4 | **环保与能耗指标硬约束** | 产线属于高能耗或产生危废排放，当地园区无环评配额导致无法开工 | 园区环保局能耗指标与危废处置资质前置论证函件 |
| 5.5 | **厂房代建及退出机制** | 政府代建厂房后企业经营不善弃租，厂房专用性强导致无法再次招租 | 协议必须明确回购条款或厂房改造成通用工业厂房的兜底方案 |
| 5.6 | **核心团队常驻本地承诺** | 核心研发和管理人员仅挂名，实际长期留驻一线城市不参与本地运营 | 约定核心技术团队在本地常驻时间（如每年不少于 180 天）与个税缴纳 |
| 5.7 | **清算与反担保措施** | 企业若未达对赌指标，无任何资产可供追偿，导致国有资金损失 | 实际控制人个人无限连带责任保证、母公司股权或核心设备质押 |
| 5.8 | **违规招商承诺审查** | 地方招商协议承诺“包税返还”等突破国家财政部、审计署规定的条款 | 严格遵循全国统一大市场与合规招商指引，规避审计合规风险 |
