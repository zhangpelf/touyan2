# 7 章内容规范 — 详细分析要点清单

> 本文档为 SKILL.md "工作流 Step 2 (分析)" 的展开参考。
> 在分析时逐章检查是否覆盖了对应要点。非所有要点都适用，根据项目类型裁剪。

---

## 第一章 项目概览

### 基本信息表（必出）

提取项目方提供的关键数据，制成表格：

| 维度               | 内容                      |
| ------------------ | ------------------------- |
| 项目名称           |                           |
| 实施主体           |                           |
| 投资总额           | 分总投 + 分期的结构       |
| 一期/二期/三期明细 | 固投 + 流资 + 设备 + 装修 |
| 建设内容           | 产品方向、产线类型        |
| 厂房需求           | 面积、洁净度、特殊要求    |
| 建设周期           | 单期多久、总周期          |
| 要素保障           | 电力、水、气等要求        |
| 带动就业           | 就业人数及岗位结构        |

### 投资节奏与结构（必出）

- 分期的资金安排、时间线
- 投资方式：纯债权 / 股权（要求政府产业基金注资）/ 混合
- 反投比例：项目方承诺多少比例反投到当地
- 资金到位前提条件（如有）

### 资金用途明细（建议出）

将投资额按用途拆成表格（设备/场地/流资/其他），方便判断合理性。

### 关键判断点

- 项目方自有资金出多少？杠杆比例是否合理？
- 资金分期的逻辑有没有说服力？
- 项目方在源地的规模如何？是真搬迁还是虚报？

---

## 第二章 行业与市场分析

### 宏观背景（1-2 段）

- 项目所在赛道的战略地位（国家政策、产业趋势）
- 与当前经济热点的关联度（AI/新能源/半导体/生物医药...）

### 市场规模（建议出数据表）

- 引用第三方数据（行业报告/券商研报/公开数据）
- 当前市场规模 + 预测增速 + CAGR
- 项目方的市场数据是否与行业共识一致？是否偏乐观？

### 增长驱动（3-5 点）

- 哪些因素在推动市场增长？
- 这些驱动因素是结构性（长期）还是周期性（短期）？
- 增长驱动是否与项目方的产品方向匹配？

### 竞争格局（必出）

- 市场集中度（CR5/CR10）
- 头部玩家及市场份额
- 项目方的市场定位和差异化
- 新进入者的壁垒在哪里（技术/客户/资金/认证）

### 关键判断点

- 项目方引用的市场数据是否可靠？有没有双源验证？
- 赛道天花板有多高？足够支撑项目方的远期目标吗？
- 如果大厂降价，项目方有生存空间吗？

---

## 第三章 项目竞争力评估

### 优势/劣势矩阵（必出，用表格）

| 维度      | 评估                                  |
| --------- | ------------------------------------- |
| 团队背景  | 核心技术团队履历、产业经验、过往业绩  |
| 技术能力  | 自研还是代工？核心专利/IP？良率水平？ |
| 产品力    | 产品性能指标对比同行、认证进展        |
| 客户基础  | 已有客户/在手订单/意向客户            |
| 产能规模  | 规划产能 vs 同行比较                  |
| 成本优势  | 原材料采购、制造成本、人工成本        |
| 品牌/渠道 | 行业知名度、销售渠道建设              |

### 差异化策略（建议出）

- 项目方计划如何切入市场？
- 差异化是否可持续？
- 如果头部厂商跟进，差异化是否失效？

### 关键判断点

- **最大变量**：团队能力和技术来源（这是所有新项目的命门）
- 有没有在手订单或少量的跑通记录？还是"万事俱备只欠资金"？
- 文档里有没有不敢写的内容？（如核心团队只字不提 → 红旗）
- 项目说的"高端"、"领先"、"独特"有没有实质证据？

## 第四章 财务效益分析

### 投资回收分析（必出，用表格）

| 指标              | 一期 | 二期 | 三期 | 整体 |
| ----------------- | ---- | ---- | ---- | ---- |
| 投资额            |      |      |      |      |
| 产值（当年/达产） |      |      |      |      |
| 净利润            |      |      |      |      |
| 投资回报率        |      |      |      |      |
| 投资回收期        |      |      |      |      |

### 盈利预测的核心假设（必出）

- 毛利率假设：对照行业平均，项目方的假设是否合理？
- 良率爬坡曲线：新产线的良率提升速度假设
- 费用率假设：研发、销售、管理费用占比
- 产能利用率假设：第一年 → 第二年 → 稳态

### 敏感性分析（建议出）

- 销售收入 ±10%/±20% 对 IRR/回收期的影响
- 毛利率 ±5% 的影响
- 建设延期 6-12 个月的影响

### 关键判断点

- 项目方的产值和利润预测属于行业什么水平？
- 有没有产能过剩、价格大幅下跌的压力测试？
- 项目方的财务数据是否逻辑自洽？（流资规模 vs 产值、单产投资强度 vs 行业）
- **尽量避免对项目方的财务预测做"加盖"**——只评估合理性和假设条件，不做外部模型验证。

---

## 第五章 地方落地价值评估

### 对地方政府的吸引力（必出，用表格）

| 维度       | 评估意见                       |
| ---------- | ------------------------------ |
| 产业契合度 | 是否符合地方产业规划？         |
| 投资密度   | 亩均投资强度如何？             |
| 产值贡献   | 达产后年产值、年税收估算       |
| 就业带动   | 直接就业 + 间接就业 + 岗位质量 |
| 产业带动   | 能否吸引上下游企业形成集群？   |
| 招商条件   | 反投比例、是否搬迁总部         |
| 品牌效应   | 项目对地方产业名片的价值       |

### 政府需配合的政策资源（必出）

- 项目方明确提出的需求清单
- 这些需求在当地政策范围内吗？
- 超出常规政策的特殊条件是什么？

### 政府端风险评估（建议出）

- 出资节奏和监管安排
- 对赌/回购条款设计建议
- 如果项目失败，厂房/设备等沉淀资产的处置

### 关键判断点

- 这不是 PE/VC 的"值不值得投"，而是"值不值得用行政/土地/财政资源换"
- 机会成本：同样资源给另一个项目，哪个产出更高？
- 项目方的真实意愿有多强？有无多城市比价嫌疑？

## 第六章 风险分析与缓释

### 风险矩阵（必出，用表格）

格式：列出 5-8 个核心风险，每个风险评估等级（高/中/低）、给出缓释措施。

| 风险类别 | 风险描述 | 等级     | 缓释措施 |
| -------- | -------- | -------- | -------- |
| 技术风险 | ...      | 高/中/低 | ...      |
| 市场风险 | ...      | 高/中/低 | ...      |
| 团队风险 | ...      | 高/中/低 | ...      |
| 资金风险 | ...      | 高/中/低 | ...      |
| 建设风险 | ...      | 高/中/低 | ...      |
| 政策风险 | ...      | 高/中/低 | ...      |
| 竞争风险 | ...      | 高/中/低 | ...      |

### 关键情景分析（建议出 2-3 个）

选最可能出问题的 2-3 个情景，展开分析：

- **情景一**：[风险场景描述] → 影响（量化）→ 应对方案
- **情景二**：[风险场景描述] → 影响（量化）→ 应对方案

### 关键判断点

- 风险不是越多越好——找出真正致命的 3-5 个
- 每个风险都要有缓释措施，"意识不到"比"有风险"更可怕
- 项目方自己有没有意识到这些风险？文档里是否主动提及？

## 第七章 综合评估与建议

### 综合评价（必出，评分表）

| 评估维度      | 评分（1-5） | 评语   |
| ------------- | ----------- | ------ |
| 赛道前景      | ★★★★★  | 1-2 句 |
| 项目本身质量  | ★★★★★  | 1-2 句 |
| 投资条件      | ★★★★★  | 1-2 句 |
| 产值/税收贡献 | ★★★★★  | 1-2 句 |
| 风险可控度    | ★★★★★  | 1-2 句 |

### 投资建议（核心产出，必出）

**总体判断**：推荐落地 / 审慎推进 / 不推荐

**分期建议**（分三期列出条件）：

| 阶段           | 建议                   | 前提条件 |
| -------------- | ---------------------- | -------- |
| 一期（X 万元） | 建议投资 / 审慎 / 暂缓 | 条件清单 |
| 二期（X 万元） | 条件触发 / 暂不考虑    | 触发条件 |
| 三期（X 万元） | 机会导向 / 暂不考虑    | 触发条件 |

**尽调重点**：列出在决策前必须核查的 3-5 个关键事项。

### 关键判断点

- 总体判断要干脆，不模棱两可
- 分期建议必须给明确的"前提条件"，让决策者可操作
- 尽调重点指向最大风险点

---

## 通用规则

1. **不输出面向地方政府/国资不好直接评价的内容**（如"这个团队不行"→"团队背景需进一步核实"）
2. **不输出未经核实的企业内部敏感信息**
3. **文档里没有的信息不要"帮项目方脑补"**（如项目方没说团队→写"项目方未披露团队信息"）
4. **每个表格都要有明确的判断导向**，不是数字堆砌
5. **总体判断必须可归结为"推荐 / 审慎 / 不推荐"三种之一**
